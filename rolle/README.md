# ROLLE · GEO-Modular

SEED ⟁ bildet den Ursprung.

Die sechs Rollen sind geometrisch angeordnet:

- ORT   → Position
- HOME  → Zentrum
- USER  → Zugriff
- USE   → Funktion
- OUT   → Ausgabe
- ROLLE → Gesamtform

Sie bilden zusammen eine modulare GEO-Struktur
um den SEED ⟁ als Mittelpunkt.

        ORT
   USER     USE

       ⟁ (HOME)

   OUT      ROLLE
