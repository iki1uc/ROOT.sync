# GEO · SEED ⟁ · ROLLE-Modular
# reine Struktur · keine Last · keine Engine

SEED:
  SYMBOL: ⟁
  BEDEUTUNG: Ursprung · Zentrum · HOME

GEO-MODULAR:
  ORT:   Position
  HOME:  Zentrum (SEED)
  USER:  Zugriff
  USE:   Funktion
  OUT:   Ausgabe
  ROLLE: Gesamtform

GEOMETRIE:

        ORT
   USER     USE

       ⟁ (HOME)

   OUT      ROLLE

REGELN:
  - SEED ⟁ ist immer Zentrum.
  - ORT liegt oben.
  - USER links.
  - USE rechts.
  - OUT unten links.
  - ROLLE unten rechts.
  - Zusammen bilden sie die GEO-Identität.
